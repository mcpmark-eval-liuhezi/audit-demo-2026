# Maintenance Audit Checklist

One checkbox per stop on the audit. Work top to bottom, tick as you go, and
open an issue for anything that needs follow-up.

- [ ] Default-branch hygiene — branch protection, required reviews, CI status
- [ ] Open pull-request review — stale PRs, missing reviewers, unresolved threads
- [ ] Issue triage — unlabelled, unassigned, or dormant issues
- [ ] Code-scanning alerts — open alerts by severity and tool
- [ ] Notification settings — watch level, mentions, and routing
